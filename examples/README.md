# Examples

| File | Package | What it shows |
|------|---------|---------------|
| [mapper_basic.py](mapper_basic.py) | mapper | Full pipeline — embed + fill in Python |
| [mapper_api.py](mapper_api.py) | mapper | Call mapper via REST API |
| [chatbot_session.py](chatbot_session.py) | chatbot | Programmatic chatbot session |
| [doc_upload_extract.py](doc_upload_extract.py) | doc_upload | Extract from document and fill PDF |
| [rag_predict.py](rag_predict.py) | rag | Predict fields + submit feedback |
| [custom_plugin.py](custom_plugin.py) | plugins | Write and register a custom plugin |

## Prerequisites

```bash
pip install "pdf-autofillr[all]"
pdf-autofillr setup
cp .env.example .env  # then add your API key
```
